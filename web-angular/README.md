# مصمم التطبيقات الذكي — Angular

واجهة المنصة (MVP) — Angular 19 · عربي RTL.

## التشغيل

```bash
git clone https://github.com/meteo2026net-oss/ibrahem-zynab-dev.git
cd ibrahem-zynab-dev/web-angular
npm install
npm start
```

http://localhost:4200

**تسجيل الدخول التجريبي:** أي بريد + كلمة مرور غير فارغة.

## المحتوى

- تسجيل دخول + حماية المسارات
- 14 مركزاً + الرئيسية
- حالة مشتركة محفوظة (localStorage)
- سيناريو متجري: تحليل → تصميم → وظائف → بيانات → بناء → اختبار → إطلاق
