# مصمم التطبيقات الذكي — v1.0.0

منصة Angular لتصميم وبناء التطبيقات (MVP احترافي كامل التدفق).

## التشغيل

```bash
git clone https://github.com/meteo2026net-oss/ibrahem-zynab-dev.git
cd ibrahem-zynab-dev/web-angular
npm install
npm start
```

- العنوان: http://localhost:4200  
- دخول تجريبي: أي بريد + كلمة مرور
