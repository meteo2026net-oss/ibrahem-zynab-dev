**الحالة:** TEST-ID PROVENANCE AUDIT / SOURCE-VERIFIED / DERIVED CATALOG CORRECTION REQUIRED  
**التاريخ:** 2026-11-15  
**المصدر:** DOCX الرئيسي، عبر النص المستخرج `master-approved-specification.txt` من Artifact ID `14140098015`.  
**مواضع المصدر:** أسطر 1-based؛ هوية المصدر وبصمته موثقتان في 103.

## 1. النتيجة التنفيذية

فحصت أنماط معرفات الاختبارات في النص المستخرج كاملاً، لا في ملخص Markdown. توجد **89 معرف اختبار فريداً ظاهراً في جداول/قوائم اختبار المصدر** موزعة على ثماني عائلات. كما توجد رموز أخرى تشبه المعرفات لكنها ليست Test IDs: `GATE-01..07` بوابات جاهزية، و`TEST-NAV-0001` مثال افتراضي داخل قالب توضيحي لا حالة اختبار معتمدة.

في المقابل، لم تظهر في النص الأصلي المعرفات المحلية الواردة في مسودة الكتالوج 80 مثل `DRAFT-AT-C01-01` أو `C05-AT-01` أو `C06-AT-01` أو `C07-AT-01`. هذه المعرفات يجب أن تصنف `DERIVED/PROPOSED` ما لم يوجد مصدر مستقل موثق لها؛ لا يجوز تسميتها SOURCE-ID-RECOVERED.

**تصحيح لازم:** فصول المراكز 19–28 تعرض في عدد من المواضع سيناريوهات قبول مكتوبة بلا Test ID أصلي. الوثيقة 104 أنشأت معرفات `SRC-AT` محلية لتحديد مواضعها فقط. لا تحول تلك السيناريوهات إلى معرفات أصلية.

## 5. تصحيح مطلوب في كتالوج 80

يجب تعديل لغة حالة المصدر في 80 كما يلي:
1. لا تستخدم `SOURCE-ID-RECOVERED` لمعرف محلي مشتق لمجرد وجود سيناريو قبول في فصل المصدر.
2. C01–C09: احتفظ بسيناريوهات القبول الأصلية كما في الوثيقة 104، مع `SRC-AT` locators محلية. عائلات DRAFT-AT/Cxx-AT تبقى DERIVED/PROPOSED.
3. C10/C11: استخدم اختبارات المصدر الأفقية AT/API حيث تنطبق، ولا تنسب الاختبار إلى مركز دون قرار مالك.
4. C12: احتفظ بـKNOW-QA وKNOW-SEC بوصفهما معرفات أصلية، مع التمييز بين اختبار توثيق تقرير الاختبار وبين اختبار تشغيل المنتج.
5. C13: احتفظ بـSET-INT بوصفها معرفات أصلية لاختبارات تكامل الإعدادات، واربطها بعمليات C13 بعد مراجعة دلالية.
6. C14: احتفظ بـDASH-INT بوصفها معرفات أصلية لاختبارات تكامل لوحة التحكم.
7. DATA وDOC عائلات أصلية ذات نطاق بيانات/وثيقة؛ لا تنسبها تلقائياً إلى كل عملية API أو حدث.

## 6. أثر التدقيق على السجلات الأخرى

- الوثيقة 102: تبقى نتيجتها بشأن غياب exact Event ID → Test ID mapping في 100 صحيحة؛ وجود 89 معرفاً أصلياً في مجالات أوسع لا يثبت تغطية الأحداث المفردة.
- الوثيقة 99: يجب أن تميز بين `SOURCE-TEST-ID` و`DERIVED-TEST-CANDIDATE`، ولا تستخدم family-level test كاختبار مفرد لعملية.
- الوثيقة 100: لا يجوز وضع معرفات EVT-96 العامة في خانة exact Test IDs.
- الوثيقة 104: `SRC-AT` local locators تظل مراجع نصية لا معرفات اختبارات أصلية.
