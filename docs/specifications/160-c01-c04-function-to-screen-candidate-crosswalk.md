## 2. قواعد التصنيف

- `SEMANTIC-CANDIDATE`: العنوان/الغرض يوحيان بعلاقة وظيفية، لكنها تحتاج تأكيد المالك.
- `CROSS-CUTTING-CANDIDATE`: القدرة قد تكون ضمن شاشة عامة أو أكثر من شاشة، ولا توجد شاشة مستقلة واضحة.
- `NO-DEDICATED-SCREEN`: لم يظهر عنوان شاشة مخصص بوضوح؛ لا يعني غياب الوظيفة من المنتج.
- لا تستخدم هذه المطابقة لإثبات 1:1؛ يمكن للوظيفة أن تظهر في عدة شاشات، ويمكن للشاشة أن تجمع وظائف متعددة.
- لا تعني المطابقة أن API أو event أو test أو Domain SoR قد اعتمد.
