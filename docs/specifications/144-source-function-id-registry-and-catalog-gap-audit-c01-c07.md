## 3. تدقيق كتالوجات الوظائف

### C01–C04
- استعاد المصدر 57 معرف وظيفة أصلية (12 + 15 + 14 + 16).
- الكتالوج التشغيلي 19 يقدم وظائف/شاشات مشتقة بصيغ مثل `C01-SCR-01` و`DRAFT-AT-C01-01`، لكنه لا يقدم هذه المعرفات الأصلية `C01-Fnn` إلى `C04-Fnn` كسجل وظائف canonical.
- لا يجوز مساواة `C01-F01` مع `C01-SCR-01` لمجرد التشابه الوظيفي أو الترتيب.
- المطلوب: إضافة source-ID aliases إلى سجل وظائف مستقل، ثم مطابقة كل وظيفة مع العقد التشغيلي المناسب، وتوثيق exact/semantic-candidate/not-mapped.

### C05–C07
- استعاد المصدر 52 معرف وظيفة أصلية (16 + 18 + 18).
- كتالوج 12 يحتوي معرفات C05-F01..16 وC06-F01..18 وC07-F01..18.
- هذا يثبت حفظ المعرفات، ولا يثبت وحده التطابق الكامل بين العناوين والنطاقات أو اكتمال مدخلات/مخرجات الوظائف والعقود.
- يلزم مقارنة نصية تفصيلية للعنوان والنطاق والمدخلات والمخرجات والصلاحيات والأخطاء والاختبارات مع B-05..B-07.

## 4. قواعد المطابقة

تستخدم حالات المطابقة التالية فقط:
- **EXACT-ID:** المعرف نفسه محفوظ حرفياً في السجل المستهدف.
- **EXACT-NAME:** العنوان مطابق حرفياً بعد تطبيع المسافات وعلامات الترقيم فقط.
- **ALIAS:** اختلاف تسمية موثق صراحة مع الاحتفاظ بالمعرف الأصلي.
- **SEMANTIC-CANDIDATE:** تشابه وظيفي يحتاج موافقة مالك المجال.
- **NOT-MAPPED:** لا يوجد مقابل موثق.
- **CONFLICT:** السجل المستهدف يعرض نطاقاً أو مسؤولية متعارضة.

لا تستخدم الترتيب الرقمي أو تشابه اسم الشاشة كدليل تطابق. ويجب أن يحتفظ السجل النهائي بـsource ID وcanonical ID (بعد الاعتماد فقط) واسم المصدر وموقعه وإصدار المصدر والمالك وحالة المطابقة.

## 5. ما لا تثبته هذه الوثيقة

- وجود معرف وظيفة لا يعني اكتمال عقد الوظيفة.
- عنوان الوظيفة لا يثبت API أو schema أو permission أو owner معتمداً.
- لا تربط هذه الوثيقة تلقائياً 109 وظيفة بـ201 عملية أو 130 معرف قبول.
- لا يوجد دليل تنفيذ أو اختبار ناجح مستنتج من هذا الجرد.
- لا تعتبر أعداد الشاشات والوظائف المتساوية دليلاً على تطابق واحد لواحد.

## 7. الحكم

**تم استرداد 109 معرفات وظائف أصلية وعناوينها ومواقعها.** فجوة حفظ معرفات المصدر في كتالوج C01–C04 مثبتة، بينما C05–C07 تحتفظ بالمعرفات في كتالوج 12 وتحتاج مراجعة تفصيلية للمحتوى. جميع المطابقات التشغيلية والملكية النهائية ما زالت بحاجة إلى مراجعة واعتماد.
