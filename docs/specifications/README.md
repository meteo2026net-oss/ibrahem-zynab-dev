## حالات التوثيق

- **APPROVED:** قرار اعتمده المستخدم صراحةً.
- **PRELIMINARY:** خط أساس مبدئي يحتاج مراجعة تقنية.
- **PROPOSED:** توصية لم تُعتمد.
- **PENDING_USER:** يحتاج قرار المستخدم.
- **PENDING_REVIEW:** يحتاج مراجعة فنية أو أمنية.
- **CONDITIONAL:** معتمد ضمن شروط محددة.
- **RECOVERED_SUMMARY:** مستعاد كملخص.
- **RECOVERED_DETAILED:** تفاصيل موسعة مستعادة وتحتاج مطابقة نهائية.
- **NOT_RECOVERED:** لم تُستعد تفاصيله.

## حقيقة مهمة عن الاكتمال

وصل تسلسل النقاشات إلى الفصل 163، لكن لا تتوفر في السياق الحالي النصوص الحرفية الكاملة لكل الفصول. لذلك هذه الحزمة تجمع ما استُعيد، وتوثق الفجوات صراحة. لا تصف نفسها بأنها جميع النصوص الأصلية أو اعتماد نهائي.
