## 4. قواعد تفسير الملكية

1. المالك المقترح يعني المركز المسؤول عن تعريف القدرة الوظيفية، وليس مالك كل خدمة تقنية تستعملها.
2. المراكز المساندة لا تنشئ ملكية مكررة للوظيفة أو للبيانات.
3. C14 هو لوحة التحكم الرئيسية وفق قائمة المراكز المعتمدة؛ التشغيل والاستمرارية قدرة مشتركة في L9/L10، وليست مركزاً خامس عشر.
4. المحاور التي تشمل الأمن أو البيانات أو المعرفة أو التشغيل قد تتقاطع مع جميع المراكز؛ يجب توثيق واجهة الخدمة المشتركة دون نقل ملكية المجال.
5. لا تُغلق أي فجوة بمجرد ربط محور بها؛ يلزم عقد وظيفة وشاشة وبيانات وصلاحيات واختبار وأدلة حسب طبيعة المتطلب.

## 7. شروط إغلاق GAP-044

تُغلق GAP-044 فقط عندما:
1. يراجع مالك كل مركز جميع المحاور المنسوبة إليه.
2. تُفكك المحاور المركبة إلى متطلبات ذرية دون فقدان النص الأصلي.
3. تُربط جميع المتطلبات بالوظائف والشاشات والبيانات والعقود والصلاحيات.
4. تُكتب معايير قبول واختبارات لكل متطلب قابل للاختبار.
5. تُراجع التغطية والازدواجية والتعارضات بين المراكز.
6. تُرفق أدلة اختبار فعلية عندما يكون الادعاء متعلقاً بالتنفيذ.
