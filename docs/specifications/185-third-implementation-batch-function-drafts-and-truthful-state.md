# 185 — الدفعة التنفيذية الثالثة: مسودة منطق الوظائف وصدق الحالة الابتدائية

- التاريخ: 2026-11-16
- الفرع: `main`
- النطاق: جعل تحويل الوصف إلى خطوات محلية قابلاً للتتبع، ومنع واجهة الوظائف والوكلاء من ادعاء اختبار أو تنفيذ غير موجود، وإزالة نتائج البناء والاختبار والنشر الوهمية من الحالة الابتدائية.

## 1. التغييرات

- `ProjectService.convertNaturalToSteps`: يقسم نص المستخدم إلى أسطر/جمل، يصنفها محلياً إلى تحقق/إجراء/نجاح/خطأ، ويضع وصفاً صريحاً بأنها مسودة تحتاج مراجعة. لا يدعي استخدام نموذج AI.
- مركز الوظائف: لا يعرض اختباراً ناجحاً محاكياً؛ الاختبار الفعلي معطل حتى ربط مشغل تنفيذ موثوق.
- مركز الوكلاء: لا ينقل المهام إلى حالات تشغيل أو مراجعة دون Orchestrator؛ زر التشغيل معطل، والطلب يسجل كحالة محجوبة لا كنجاح.
- مركز التصميم: تغيير زر «توليد بالذكاء الاصطناعي» إلى «إضافة شاشات مقترحة» مع توضيح أن الاختيارات من قالب محلي.
- الحالة الابتدائية: جميع حالات الاختبار PENDING، ولا توجد حزمة APK جاهزة، وعناصر قائمة الإطلاق غير مكتملة افتراضياً.

## 2. اختبارات مضافة

أضيف `project.service.spec.ts` للتحقق من:
- تصنيف الخطوات المشتقة من النص.
- عدم تغيير نتائج الاختبارات تلقائياً.
- عدم إعلان وجود APK دون بناء.
- عدم تسجيل نشر بمجرد اكتمال checklist.
- عدم تشغيل الوكلاء دون backend.
- عدم الادعاء بأدلة بناء/اختبار/إطلاق في الحالة الابتدائية.

## 3. التحقق

- تم إنشاء workflow Web Angular CI سابقاً، وآخر تشغيل مكتمل مؤكد للدفعة السابقة كان ناجحاً.
- تغييرات هذه الدفعة أحدثت تشغيل CI جديداً؛ حالته عند إعداد هذا التقرير: **PENDING**، ولا يُعلن نجاحه قبل اكتماله.
- لم يتم نشر التطبيق.

## 4. الحدود الحالية

- تحليل الفكرة في المعالج ما زال heuristic محلياً، وليس خدمة AI.
- تحويل الوظائف مسودة قواعد محلية وليس مفسراً تنفيذياً.
- محرك التصميم لا يزال نموذجاً أولياً محلياً.
- التخزين ما زال localStorage، وليس قاعدة بيانات خادمية.
- المصادقة ما زالت مغلقة افتراضياً إلى حين توصيل موفر هوية.
- لا تزال خدمات الذكاء الاصطناعي، التنسيق، التوليد، الاختبار، البناء والنشر الفعلية غير موصولة.
