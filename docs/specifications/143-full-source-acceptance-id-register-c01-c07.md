## 3. قواعد الاستخدام

1. احتفظ بمعرفات `Cxx-AT-nn` كما وردت في المصدر ولا تستبدلها بمعرفات `DRAFT-AT` أو `SRC-AT`.
2. عبارة «غير مذكور في جدول المصدر» تعني أن الجدول المستعاد لا يقدم نتيجة متوقعة منفصلة للحالة؛ لا تعني أن الاختبار لا يحتاج نتيجة.
3. لا تحوّل وصف السيناريو إلى خطوات تنفيذ أو بيانات اختبار أو assertions من دون مراجعة مالك C07 والمالك الوظيفي.
4. لا تعلن PASS/FAIL دون run ID وcommit/build وبيئة وبيانات اختبار ونتيجة فعلية وأدلة.
5. استخدم وثيقة 142 للفصل بين هذه القائمة وبين 86 SRC-AT locators المستعادة من DOCX؛ لا يوجد تطابق واحد لواحد معتمد بينهما.

## 4. بوابة الإغلاق لكل حالة

لا تصبح الحالة قابلة للتنفيذ والاعتماد حتى يتوفر:
- مصدر/متطلب أو وظيفة محددة.
- مالك اختبار ومالك مجال.
- شروط مسبقة وبيانات اختبار معزولة.
- خطوات قابلة للتكرار.
- نتيجة متوقعة قابلة للقياس، بما فيها السلوك السلبي عند الحاجة.
- منصة وبيئة وإصدارات.
- دليل تنفيذ ونتيجة مراجعة.
- روابط إلى Operation/Event/Approval عند انطباقها.

## 5. الحكم

**تم استرداد 130 معرفاً ووصف سيناريو من Export 07، لكن 115 منها لا تحتوي نتيجة متوقعة منفصلة في جدول المصدر. لا يمثل هذا السجل خطة اختبار تنفيذية كاملة ولا إثبات اجتياز.** ويظل اعتماد الملاك، واستكمال التفاصيل، والربط المفرد، والتنفيذ، وجمع الأدلة أعمالاً مفتوحة.

هذه الوثيقة تفريغ مصدر منظم ومشتق لأغراض التتبع، وليست موافقة على بدء البرمجة.
