# 11 — سجل الفصول ومصفوفة التتبع

## 1. الغرض

يجمع هذا السجل أرقام الفصول التي أمكن استعادتها من العمل السابق، ويمنع اعتبار وجود رقم فصل دليلاً على توفر نصه الكامل. يجب أن يُحدّث عند استعادة أي محتوى أصلي.

لا تُستنتج موضوعات الفصول غير الموجودة في الجدول ولا يُعاد ترقيم الفصول من الذاكرة الجزئية. يجب استعادة سجل الفهرس الأصلي لتحديد الفصول المفقودة أو المعاد ترقيمها.

## 3. مصفوفة التتبع الإلزامية

`GOAL → BR → REQ → FUNC → SCREEN → DATA → API/EVENT → PERMISSION → TEST → EVIDENCE → RELEASE`

لكل عنصر معرف ثابت، ومالك، وحالة، وإصدار مصدر، وعلاقات تتبع.

## 4. سجل عناصر التتبع

| العنصر | الحد الأدنى من البيانات |
|---|---|
| Goal | الهدف ومؤشر النجاح |
| BR | الحاجة التجارية والمستخدم المستفيد |
| REQ | نص المتطلب ومصدره وأولويته وحالته |
| FUNC | السلوك والمدخلات والمخرجات والأخطاء |
| SCREEN | معرف الشاشة ومسار الوصول وحالاتها |
| DATA | الكيان والمالك والحقول والقيود |
| API/EVENT | العقد والإصدار والمصادقة والأخطاء |
| PERMISSION | الدور والنطاق والشرط والقرار |
| TEST | خطوات الاختبار والبيانات المتوقعة |
| EVIDENCE | سجل التنفيذ والنتيجة والوقت والبيئة |
| RELEASE | الإصدار الذي يتضمن التغيير |

## 5. قاعدة الاكتمال

لا يوسم المتطلب بأنه جاهز للتنفيذ إذا لم تُعرف مدخلاته ومخرجاته وحالات فشله وصلاحياته وبياناته واختبار قبوله واعتمادياته. ولا يوسم بأنه مكتمل بعد التنفيذ إلا بدليل اختبار ناجح وإصدار محدد.


## 6. استعادة إضافية ونتائج تدقيق أولي

استُعيدت تفاصيل الفصول 125 و141 و143 و151 و152 و158–163 من ملفات التصدير 02–07. راجع [ملف الاستعادة 16](16-recovered-chapters-125-141-158-163-and-audit-findings.md) و[ملف الاستعادة 18](18-recovered-chapters-143-151-152-and-shared-services.md) للحصول على التفاصيل والنتائج.

تعارض حرج: الفصلان 158 و159 يسميان C14 «التشغيل والاستمرارية»، بينما قائمة المراكز المعتمدة تجعل C14 «لوحة التحكم الرئيسية» وتجعل التشغيل والاستمرارية قدرة مشتركة في L9/L10. يجب تصحيح وثيقة التجميع مع الاحتفاظ بالنص المصدر كسجل تاريخي.


## 7. ملاحظة الترقيم وإعادة تنظيم الفصول

استُعيدت في مصادر مختلفة فصول 132–135 ثم 154–157 بموضوعات متداخلة جزئياً. الفصل 134 يعالج ملكية البيانات، بينما الفصل 156 مدرج لاحقاً للموضوع نفسه؛ والفصل 135 يعالج عقود المراكز، بينما الفصل 155 يقدم حوكمة أوسع للعقود. لا يجوز حذف أي نسخة تاريخية أو دمجها دون خريطة مقارنة تحدد الإضافات والتغييرات والقرارات. الفصل 157 ما زال مطلوباً في المصدر، ولم يُستعد بعد.
