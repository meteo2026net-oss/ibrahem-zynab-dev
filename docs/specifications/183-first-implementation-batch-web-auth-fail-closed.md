# 183 — الدفعة التنفيذية الأولى: إغلاق المصادقة التجريبية في واجهة الويب

- التاريخ: 2026-11-16
- الفرع: `main`
- نطاق الدفعة: إزالة تسجيل الدخول التجريبي الذي كان يمنح دور admin محلياً، واعتماد سلوك fail-closed إلى حين ربط مزود هوية موثوق.
- هذه أول دفعة كود بعد موافقة المالك الصريحة على بدء البرمجة.

## 1. التغييرات المنفذة

| الملف | التغيير |
|---|---|
| `web-angular/src/app/core/auth.service.ts` | إزالة استعادة الجلسة من localStorage، وعدم قبول بيانات اعتماد محلية، وعدم إنشاء مستخدم بدور admin. |
| `web-angular/src/app/features/login/login.component.ts` | إزالة بيانات الدخول الافتراضية ومسار إنشاء الجلسة التجريبية. |
| `web-angular/src/app/features/login/login.component.html` | استبدال نموذج الدخول التجريبي برسالة صريحة بأن مزود الهوية الخادمي لم يُهيأ بعد. |
| `web-angular/src/app/core/auth.service.spec.ts` | إضافة اختبارات وحدات لسلوك الرفض الافتراضي وعدم استعادة جلسة غير موثوقة ومسح الجلسة. |

## 2. الضمانات الناتجة

- لا يمكن إنشاء جلسة مستخدم بمجرد إدخال بريد وكلمة مرور غير فارغين.
- لا تتم استعادة دور admin من localStorage.
- حالة المصادقة تبدأ دائماً بلا مستخدم، وتبقى غير مصادق عليها إلى أن يتم تنفيذ ربط هوية موثوق.
- مسارات المصمم المحمية تبقى محمية بواسطة authGuard، ولذلك لا يتجاوز المستخدم صفحة الدخول غير المهيأة.
- لم تتم إضافة أي مفاتيح أو أسرار أو بيانات اعتماد.

## 3. ما لم يكتمل بعد

- لم يتم ربط Firebase Auth أو أي مزود هوية خادمي؛ لا توجد تهيئة موثوقة أو إعداد بيئة مثبت في ملفات الويب المفحوصة.
- لم تُنفذ أدوار وصلاحيات server-side أو tenant/workspace membership.
- هذه الدفعة تجعل الدخول مغلقاً بأمان لكنها لا توفر تسجيل دخول إنتاجياً بعد.
- يلزم تنفيذ مزود الهوية واختبارات التكامل وتحديث مسارات المصادقة بعد تحديد إعدادات مشروع الهوية الفعلية.
- لم يُشغّل npm install أو npm test أو ng build في هذه الجولة؛ الاختبار المضاف مصدر محفوظ فقط وليس PASS مثبتاً.
- لا نشر تم في هذه الجولة.

## 4. حدود التغيير

- لم يتم تعديل Android أو Firestore rules أو API أو schema أو database.
- لم تُنشأ جلسات أو اتصالات خارجية.
- لا يُعد هذا الإصلاح إغلاقاً لكل مخاطر الأمن المسجلة في الوثائق 178–182، ولا يجعل التطبيق جاهزاً للنشر.
