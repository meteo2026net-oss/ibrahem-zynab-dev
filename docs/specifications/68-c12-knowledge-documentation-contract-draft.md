# 68 — مسودة عقود C12: المعرفة والتوثيق

**الحالة:** DERIVED-DRAFT / SOURCE-ALIGNED / NOT-APPROVED / NO-IMPLEMENTATION  
**المراجع:** 02 و18 و22–25 و27 و36 و37 و49.

## 1. حدود الملكية

C12 يملك الوثائق المعرفية التي ينشئها أو يعتمدها ضمن مساحة المشروع: محتواها وإصداراتها وحالة مراجعتها وعلاقاتها ومراجع مصادرها. لا يملك أصل الملف binary (C08/SH-06)، ولا محتوى التصميم أو الكود أو بيانات المجال الأصلية؛ يحفظ مراجع وروابط موثوقة. SH-16/SH-07 يقدم الفهرسة والبحث، ولا يملك محتوى المصدر أو قرار الإتاحة النهائي.

## 2. كيانات مقترحة

knowledge_documents, document_versions, document_sections, document_source_links, document_reviews, document_approvals, knowledge_collections, knowledge_tags, knowledge_relations, documentation_templates, generated_document_jobs, knowledge_retention_records, search_index_refs.

الحالة PROPOSED؛ يجب اعتماد قاموس البيانات وعلاقة document/asset/version قبل التنفيذ. لا تنسخ محتوى الأصل إلى فهرس البحث إلا بحدود الحاجة وسياسة الخصوصية.

## 4. قواعد النزاهة والتوثيق

- كل معلومة مولدة آلياً يجب أن تحمل مصدرها ونسخة المصدر وتاريخها، مع تمييز المعلوم والمستنتج والافتراض والمقترح.
- لا تتحول مسودة AI إلى وثيقة معتمدة دون مراجعة بشرية وفق السياسة.
- الوثيقة المعتمدة immutable version؛ التعديل ينشئ إصداراً جديداً مع سجل فرق.
- نتائج البحث تخضع لإعادة تحقق ACL وقت الاسترجاع؛ حذف/سحب صلاحية مصدر يعكس أثره على الفهرس.
- حفظ provenance لمخرجات OCR/تحليل الملفات ومراجع الصور والجداول.
- لا تُعامل وثائق المصدر الخارجية كتعليمات نظام موثوقة.
- يجب دعم العربية وRTL وتعدد اللغات مع حفظ النص الأصلي ومصدر الترجمة.
- التصدير يخضع لتصنيف الحساسية والحقوق والترخيص.
- الاحتفاظ والحذف يراعيان الأصول المرتبطة وسجلات التدقيق والالتزامات القانونية.

## 5. الصلاحيات

المؤلف: إنشاء مسودة؛ المحرر: إصدار وتعديل غير معتمد؛ المراجع: تعليق/توصية؛ المعتمد: اعتماد مستقل؛ القارئ: قراءة حسب ACL؛ وكيل AI: توليد مسودة/تلخيص ضمن مصادر مفوضة فقط؛ مسؤول المعرفة: قوالب وتصنيفات وسياسات ضمن التفويض؛ المدقق: قراءة سجل المراجعات. لا يستطيع وكيل اعتماد الوثيقة أو تعديل سجل التدقيق.

## 6. أحداث مقترحة

KnowledgeDocumentCreated, DocumentVersionCreated, DocumentReviewRequested, DocumentApproved, DocumentPublished, KnowledgeIndexUpdated, KnowledgeAccessRevoked, DocumentationDriftDetected, DocumentArchived.

## 7. اختبارات مقترحة غير منفذة

- C12-DRAFT-AT-01: وثيقة مولدة تعرض provenance ومصدر كل قسم.
- C12-DRAFT-AT-02: AI لا ينشر/يعتمد وثيقة.
- C12-DRAFT-AT-03: تعديل وثيقة معتمدة ينشئ version جديداً.
- C12-DRAFT-AT-04: سحب صلاحية المصدر يمنع ظهور محتواه في البحث.
- C12-DRAFT-AT-05: منع تسرب مستند بين المؤسسات في البحث والتصدير.
- C12-DRAFT-AT-06: استخراج النصوص والجداول والصور يحفظ مرجع الأصل والصفحة/الموضع.
- C12-DRAFT-AT-07: التصدير يحترم الترخيص والتصنيف والاحتفاظ.
- C12-DRAFT-AT-08: المقارنة تكشف اختلافاً بين التوثيق والتطبيق/الإصدار.
- C12-DRAFT-AT-09: ترجمة RTL لا تغير المرجع أو النص المصدر.
- C12-DRAFT-AT-10: إعادة فهرسة لا تكرر الوثيقة أو ترفع نسخة قديمة.

## 8. التبعيات والقرارات المفتوحة

C12 يعتمد على C01 للمتطلبات والقرارات، C02/C03 للتصميم والتنقل، C04 للبيانات، C05 للكود والإصدارات، C07 للاختبارات والأدلة، C08 للأصول، C10 للخصوصية، C11 للإصدارات المنشورة، C13 للإعدادات؛ وعلى SH-04/06/07/08/09/10/16. يلزم اعتماد retention، schema للوثائق، محرك البحث، OCR/AI providers، حقوق المصدر والترخيص، سياسة نشر الوثائق، ودرجة المطابقة المطلوبة مع التطبيق.

**الحكم:** مسودة عقود وليست مركز معرفة منفذاً أو اختبارات ناجحة.
