## 6. ضوابط الإغلاق

1. مراجعة كل إحالة OWN36/OWN72 مع النص الكامل للقرار ونطاقه والمالك والموافق وحالته.
2. لا تحول أي قرار OPEN إلى APPROVED بسبب وجود معرفه في السجل.
3. إسناد قرار مفرد أو مجموعة قرارات مؤهلة لكل عملية، أو توثيق N/A مع السبب وموافقة المالك.
4. حسم العمليات الـ62 في C01/C02/C03/C05، مع التمييز بين ملكية المجال وحدود SH.
5. مراجعة معرفات OWN36 غير المستخدمة في 97 على مستوى الكيانات والحقول والأحداث والموافقات.
6. ربط كل قرار باختبار سلبي/إيجابي مفرد عند الحاجة، مع run evidence بعد السماح بالتنفيذ.
7. لا تعد هذه المصفوفة تفويضاً لتعديل OWN history أو نقل عملية بين المراكز.
