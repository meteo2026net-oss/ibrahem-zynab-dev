# 66 — مسودة عقود C10: الأمن والحوكمة

**الحالة:** DERIVED-DRAFT / SOURCE-ALIGNED / NOT-APPROVED / NO-IMPLEMENTATION  
**المراجع:** 03 و13–16 و23–27 و33–38 و43 و47 و49 و56.  
**ملاحظة حاسمة:** Zero Trust/SEC-REV-01 متعارض في المصدر؛ يبقى PENDING_USER ولا يُعلن معتمداً هنا.

## 1. الحدود والملكية

C10 يملك سياسات الأمن والخصوصية والحوكمة، نماذج المخاطر، متطلبات المراجعة، الاستثناءات، ومتابعة المعالجة. لا يملك بيانات المجال أو كلمات المرور أو محرك التفويض العام. SH-01 يملك الهوية والمصادقة والجلسات؛ SH-02 ينفذ قرارات السماح/الرفض وفق السياسات؛ SH-04 يملك سجل التدقيق المركزي؛ مالك كل مركز يملك حماية بياناته وتطبيق العقود. لا يجعل C10 أو SH-02 الواجهة الأمامية مصدراً للصلاحية.

## 4. قواعد الحوكمة والصلاحيات

- fail-closed عند غياب actor أو policy أو tenant scope أو تعذر التحقق من التفويض.
- فصل المهام: طالب التغيير لا يعتمد التغيير الحساس لنفسه حيث تتطلب السياسة موافقاً مستقلاً.
- أقل صلاحية، صلاحية مؤقتة، نطاق محدد، انتهاء تلقائي، وتسجيل سبب التفويض.
- الوكيل لا يغير صلاحياته ولا سياساته ولا سجل التدقيق ولا يعتمد عمله أو استثناءه.
- فصل اقتراح AI عن التنفيذ؛ التنفيذ عبر خدمة المجال بعد التحقق والموافقة.
- سجل التدقيق المركزي غير قابل للتعديل من مراكز المجال أو الوكلاء؛ سياسة التصحيح تكون بإضافة حدث تصحيحي.
- عزل مؤسسي على مستوى API/database/storage/cache/search/logs/backup؛ لا يكفي إخفاء واجهة.
- لا تعتبر المراجعة الساكنة اختبار اختراق؛ ولا تصدر شهادة امتثال بلا نطاق وأدلة مستقلة.
- Zero Trust: الحالة الحالية PENDING_USER بسبب تعارض DEC-CONFLICT-02 في الوثيقة 56؛ لا تعتمد هذه المسودة المفهوم كقرار محسوم ولا تلغيه.

## 5. الاختبارات المقترحة غير المنفذة

- C10-DRAFT-AT-01: غياب policy/actor يؤدي إلى رفض آمن.
- C10-DRAFT-AT-02: رفض cross-tenant حتى مع معرف مورد صحيح.
- C10-DRAFT-AT-03: المستخدم لا يعتمد تغييره الحساس بنفسه عند اشتراط الفصل.
- C10-DRAFT-AT-04: الوكيل لا يرفع صلاحياته أو يعتمد مخرجاته.
- C10-DRAFT-AT-05: لا يستطيع مركز أو وكيل تعديل/حذف audit event.
- C10-DRAFT-AT-06: سحب عضوية/صلاحية يبطل الجلسات أو الوصول وفق السياسة.
- C10-DRAFT-AT-07: الاستثناء منتهي الصلاحية لا يمنح وصولاً.
- C10-DRAFT-AT-08: إغلاق finding يتطلب evidence مرجعياً واختبار تحقق.
- C10-DRAFT-AT-09: الأسرار لا تظهر في logs أو exports.
- C10-DRAFT-AT-10: اختبارات العزل تشمل cache/search/backup وليس قاعدة البيانات فقط.
- C10-DRAFT-AT-11: تعذر خدمة التفويض لا يؤدي إلى السماح.
- C10-DRAFT-AT-12: تعطيل وكيل يوقف مهامه/أدواته الجديدة ويحتفظ بسجلها.

## 6. الاعتماديات والقرارات المفتوحة

يعتمد C10 على C01–C14 بوصفهم مالكي مجالات، SH-01/02/03/04/06/08/09/12/13/14/15، وC13 لإدارة إعدادات السياسات دون تجاوز مالكها. يلزم اعتماد مصفوفة RBAC/ABAC، تصنيف البيانات، سياسة الاحتفاظ والخصوصية، threat model، ضوابط الوكلاء، معايير التحقق، الاستثناءات، SEC-REV-01/Zero Trust، ونطاق اختبارات الأمن المستقلة.

**الحكم:** مسودة حوكمة لا تعني اعتماد Zero Trust ولا نجاح اختبار أمني.
