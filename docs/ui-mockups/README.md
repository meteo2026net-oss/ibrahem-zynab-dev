# نماذج الواجهات الرئيسية — مصمم التطبيقات الذكي

UI Mockups (HTML + CSS) للواجهات الرئيسية للمنصة.

## المعاينة

افتح الملف:

```
docs/ui-mockups/index.html
```

في المتصفح (أو عبر GitHub Pages لاحقاً).

## المحتوى

| الملف | الوصف |
|-------|--------|
| `index.html` | فهرس جميع المراكز |
| `css/app.css` | نظام التصميم الموحّد (RTL، ألوان، مكونات) |

## ملاحظات

- الواجهات **تجريبية (Mockups)** وليست المنتج النهائي.
- اللغة العربية وRTL أساسيان.
- السيناريو المرجعي: مشروع «متجري».
- المرجع التفصيلي: `docs/specifications/00_MASTER_SPECIFICATION.md`
