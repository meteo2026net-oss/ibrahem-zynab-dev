## ما استُعيد مبدئياً

- الفصل 125: تفاصيل الشاشات 11–20 ونموذج بيانات التكاملات وبوابات الاعتماد.
- الفصل 141: إدارة التكلفة والميزانيات والموارد.
- الفصول 158–163: مواد المراجعة الأمنية واعتماديات المراكز وسجل القرارات وتدقيق الوثيقة وهيكل الإصدار والملخص التنفيذي.

راجع [سجل الاستعادة ونتائج التدقيق](../specifications/16-recovered-chapters-125-141-158-163-and-audit-findings.md) و[سجل النواقص](../specifications/17-gap-register-and-next-audit-plan.md).

## حدود الإثبات

1. وجود سبعة ملفات في هذا المجلد لا يثبت أنها تصدير كامل ومستقل لكل روابط المشاركة السبعة التي أرسلها المستخدم.
2. لا يجوز استنتاج أن فصلاً غير موجود في المصدر لمجرد عدم ظهوره في ملخص أو فهرس؛ يجب البحث في المتون الأصلية المتاحة وتسجيل نطاق البحث.
3. يجب حفظ اسم الملف الأصلي، وحجمه، وتاريخ استلامه، وحدود النص المستخرج، وعلاقة التداخل مع الملفات الأخرى عند إضافة أي مصدر.
4. النصوص المصدرية أدلة تاريخية؛ لا تصبح التوصيات قرارات معتمدة إلا بوجود موافقة مستقلة موثقة في سجل القرارات.

## حالة المشروع

الأرشفة والاستعادة لا تعنيان اعتماد المواصفات نهائياً ولا تمثلان إذناً ببدء البرمجة. لم يُجر أي تعديل على كود التطبيق ضمن أعمال الأرشفة والتدقيق الوثائقي.
